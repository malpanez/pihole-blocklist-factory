Modify `_fetch_http` (NET-01, NET-03):

1. Change signature to:
   ```python
   def _fetch_http(
       url: str,
       timeout_s: int = _REQUESTS_TIMEOUT_DEFAULT,
       user_agent: str = _USER_AGENT,
       conditional_headers: dict[str, str] | None = None,
   ) -> tuple[str, str | None, str | None]:
   ```
   Return type changes from `str` to `tuple[str, str | None, str | None]` (content, etag, last_modified).

2. Inside the function, build headers dict:
   ```python
   headers: dict[str, str] = {"User-Agent": user_agent}
   if conditional_headers:
       headers.update(conditional_headers)
   ```

3. In the retry loop, BEFORE `r.raise_for_status()`, add 304 check:
   ```python
   if r.status_code == 304:
       return "", r.headers.get("ETag"), r.headers.get("Last-Modified")
   r.raise_for_status()
   return r.text, r.headers.get("ETag"), r.headers.get("Last-Modified")
   ```

4. Update the unreachable return at end to `return "", None, None  # pragma: no cover`

Modify `fetch_to_cache` (NET-02, NET-04):

5. In the HTTP branch (the `case _:` block), BEFORE calling `_fetch_http`, load prior metadata and build conditional headers:
   ```python
   prior = _load_metadata(metadata_path)
   cond: dict[str, str] = {}
   if prior and target.exists():
       if prior.get("etag"):
           cond["If-None-Match"] = prior["etag"]
       if prior.get("last_modified"):
           cond["If-Modified-Since"] = prior["last_modified"]
   content, resp_etag, resp_last_modified = _fetch_http(url, timeout_s=timeout_s, conditional_headers=cond or None)
   ```
   Note: only build conditional headers when `target.exists()` too (per Pitfall 5 from research — stale sidecar without cache file).

6. After the `_fetch_http` call, handle 304 (content is empty string and we had conditional headers):
   ```python
   if not content and target.exists() and cond:
       existing_meta = SourceMetadata(
           source_id=source_id,
           hash=prior["hash"],
           size_bytes=prior["size_bytes"],
           line_count=prior["line_count"],
           parsed_ok=0,
           sanitized_ok=0,
           etag=resp_etag or prior.get("etag"),
           last_modified=resp_last_modified or prior.get("last_modified"),
           fetch_timestamp=time.time(),
       )
       _save_metadata(metadata_path, existing_meta)
       return target, existing_meta
   ```
   This block MUST come before `target.write_text(content, ...)`.

7. Move `target.write_text(content, ...)` into the match/case branches or after the 304 guard so it only runs on actual content. The cleanest approach: keep the match/case for file:// and local paths unchanged, and for the HTTP branch set `content` from the tuple, then after the 304 guard falls through, proceed to `target.write_text(content, ...)` as before.

8. On HTTP 200 path, populate etag/last_modified in the SourceMetadata constructor:
   ```python
   metadata = SourceMetadata(
       source_id=source_id,
       hash=content_hash,
       size_bytes=len(content.encode(_HASH_ENCODING)),
       line_count=line_count,
       parsed_ok=0,
       sanitized_ok=0,
       etag=resp_etag,
       last_modified=resp_last_modified,
       fetch_timestamp=time.time(),
   )
   ```
   For non-HTTP paths (file:// and local), etag and last_modified remain None (unchanged).

Key constraints:
- Check `r.status_code == 304` BEFORE `r.raise_for_status()` (Pitfall 1)
- Guard `prior` with `if prior and target.exists():` (Pitfalls 3 and 5)
- SourceMetadata is `frozen=True` — always construct new instances
- `parsed_ok=0` and `sanitized_ok=0` on 304 are correct (caller fills later)
